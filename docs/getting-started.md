# 安装与常见问题

[回到首页](../README.md)

## 安装目录

完整目录应为 `~/.codex/skills/paper-to-html-v2.4/SKILL.md`，旁边保留 `agents/`、`references/`、`scripts/`、`assets/`。不要只复制 SKILL.md，也不要多套一层目录。已有安装先在技能目录外备份，下一轮或新聊天确认识别。

名称沿用既有带点版本约定；通用名称校验器可能拒绝此格式。仅在 Codex 做过测试，其他 Agent 尚未测试，不把支持 SKILL.md 等同于已经兼容。

## 什么需要安装依赖？

仅打开静态阅读页不需要 Python 或模型密钥。制作需要助手读取 PDF；组件装配和本地服务需要 Python，PDF 裁图需要 PyMuPDF；可选浏览器回归另需 Node.js、Playwright 与浏览器。演示服务只展示现有内容，不生成论文解释。

## 笔记为什么保存不了？

`file://` 预览不能把随手记写入项目，请通过该论文的本地服务打开。浏览器草稿、个人标黄与项目笔记分别存储。当前没有断线自动补存，也不会即时调用 GPT。电脑的 `127.0.0.1` 不能供手机直接访问。

演示服务启动后保持终端运行，Ctrl+C 停止。端口被占用时选择空闲端口，并使用相同端口打开页面。测试笔记用复制的演示目录，不用真实项目队列。

## 制作耗时与费用

维护者提供过单次记录：约 50 分钟、Plus 账户周额度约 15%，详见[使用记录](usage-observation.md)。尚无统一时长、Token 或费用基准。页数、图的复杂度、PDF 质量、缺失资料和模型选择都会影响制作。完整带读包含逐源核对，不承诺一键准确转换。

## 校验下载包

与 Release 的 `.sha256` 对照：PowerShell 使用 `Get-FileHash ./paper-to-html-v2.4.zip -Algorithm SHA256`；Linux 使用 `sha256sum paper-to-html-v2.4.zip`；macOS 使用 `shasum -a 256 paper-to-html-v2.4.zip`。

## 怎样反馈讲解错误？

提供版本、浏览器、页码/图号、具体疑问和可公开的最小依据。不要提交私人笔记、凭据或未经许可的论文全文。
