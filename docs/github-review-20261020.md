## 仍需你审查的重点

### P1：演示与当前组件版本不一致

依据：`demo/paper-reading.html` 内仍有早期六类术语颜色和旧预览结构；当前 v2.4 规则是按领域选择分类，生物学最多使用固定五类，且预览有明确的关闭与键盘要求。公开演示只能证明这份旧演示的界面，不能作为当前版本验收证据。

影响：访客试到的东西与推荐版说明不完全一致，降低信任，也可能提交重复的旧问题。

建议：下一轮用 v2.4 装配同一原创演示，逐项验收卡片返回、标黄、预览与笔记；更新截图。不要只换配色或写“最新演示”就算迁移。

**请审查：是否优先同步中英文原创演示到 v2.4？** 本次未改演示产品内容。

### P1：还没有低门槛在线试用入口

依据：GitHub 仓库 API 的 `has_pages=false`、`homepage=null`；README 指向下载原始 HTML。文件页本身不运行网页。

建议：可用 GitHub Pages 只发布精选静态演示文件，不能直接托管全部 docs/或真实项目。在线版说明不能保存本地项目笔记，不加模型密钥，也不伪装成在线论文生成服务。部署成功并真实访问检查后再添加“在线体验”链接。

**请审查：是否启用静态演示站？中文默认还是中英文选择页？** 本次未启用 Pages 或改变仓库设置。

### P1：缺少能核查真实质量的公开样例

依据：仓库公开演示是原创模拟柱图；之前私有/本机论文的检查记录不能替代可公开复核的真实案例。现有模拟例子的价值是说明界面，不足以展示复杂类群、方法、关键条件和跨图论证。

建议：选择有明确再分发权限的论文或授权小片段，提供源文定位、完整对应译文、一幅复杂图、独立知识卡和论证链，并标出资料和验收边界。优先一份扎实案例，再扩展第二种论文类型；不能为演示擅自公开现有笔记或论文材料。

**请审查：是否愿意选一篇开放许可论文做公开案例？** 本次未上传用户论文、真实笔记或本机论文截图。

### P2：别人能否顺利安装和完成第一篇，仍缺外部验证

依据：主要验证来自当前用户的 Windows/Codex 环境；CI 验证组件，不等于另一位用户能完成安装和首次生成。Skill 名称含点号，通用名称验证器拒绝此格式；当前实际调用可用并不证明所有安装器接受。

建议：先保留用户确认的版本命名，做干净环境安装和一次新用户首次使用记录。之后再决定是否增加符合通用命名的稳定别名；不能为了宣传兼容性直接改调用名或声称支持全部 Agent。

**请审查：继续只定位 Codex，还是投入验证其他 Agent？** 当前首页维持 Codex、中文优先。

### P2：耗时、费用和质量缺少可比较基准

依据：尚无统一的完整生成时长/Token/费用数据；Darwin 本轮为 3 个受控决策探针，2 票轻微改善、1 票持平，不能宣称翻译或教学效果显著提升。

建议：固定公开来源、模型/版本、环境、输入范围和验收项，记录完整一篇的耗时、用量、人工修订点与残留错误。发布数据时注明条件；暂时不写“几分钟完成”或“提升百分之几”。

**请审查：是否接受一次有记录的完整制作基准？** 本次没有编造性能宣传。

### P2：回归测试对外展示还可以更完整

依据：当前 GitHub Actions 检查 JS 语法与 Python 测试，v2.4 的最近运行成功；浏览器回归脚本存在，但未在该 workflow 中运行。语义核对仍依赖人工/助手逐源检查。

建议：将可重复的合成页面浏览器检查纳入 CI；论文翻译和科学推理的验收单独保留，不把绿色徽章解释为“论文解释正确”。这属于测试设施改动，需单独验证，不和本次文档修饰混在一起。

**请审查：是否追加浏览器 CI？** 本次只展示现有组件检查状态。

### P3：发现与分享入口尚可改进

依据：已存在 10 个相关 topics，不是“没有标签”；About 已有英文一句话描述。尚无主页地址。分享预览图片是否在 GitHub 设置中配置，本次未核实，不能断言缺失。

建议：保留已有 topics，仅评估补充 `agent-skills`、`research-tools`、`literature-review` 等准确类别；主页地址等在线演示就绪后再填。提供分享图草稿后再上传设置，不用不相关标签蹭搜索。

**请审查：是否调整 About/topics，以及提供分享图？** 本次未更改远端设置。

## 推荐顺序

先同步演示 → 再静态在线体验 → 做一个可复核真实案例 → 验证干净安装和完整制作成本 → 扩展运行时。前三项直接改善“能看到、能试、能相信”的路径，属于判断依据，不是已测得的 Star 增长效果。

展示重写本身不能补足科学质量验证。文案保留当前能力边界，也不虚构用户量、推荐语、对比优势或 Star 成长承诺。
