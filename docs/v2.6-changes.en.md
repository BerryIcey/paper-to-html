# paper-to-html v2.6

Released 2026-11-11. Preserves captions and translations, the figure overview and author findings as separate blocks. Subsequent walkthroughs combine measurement, data construction, visual encoding and evidential roles rather than fixed chart templates. Explanation depth follows each item's current role. Prefer author-discussed examples that can be located in the current figure; retain exceptions and source conflicts.

Use concise blocks, comparisons and small tables as needed. New v2 guides require an independent approved-content baseline for build and publication; missing prose containers, changed text/numbers, reordered blocks and explicit hidden states reject publication. Legacy v1 input remains compatible. Figure context blocks retain pale backgrounds and left borders for both semantic v2 markers and legacy classes.

Validation: 50 Python tests and three isolated browser regressions passed; 45 package files checked against source. These checks do not establish scientific accuracy or whole-paper rendering quality. Existing public-paper examples were not regenerated. Dotted Skill names retain the existing generic-validator limitation.
