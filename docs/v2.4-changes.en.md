# v2.4: Darwin-assisted acceptance workflow

**No new features and no additional manual optimization.** Relative to v2.3, this release only contains the acceptance workflow adjustment produced with [Darwin Skill](https://github.com/alchaincyf/darwin-skill), independent paired review, and user confirmation.

Four separate acceptance tracks cover prose/translation, figures, knowledge cards plus the article argument, and assistive tools. A final walkthrough connects them in the same final reader. Failures require scoped repair and retesting; unavailable evidence is reported explicitly.

Paired decision probes: two judges preferred the revision slightly; one judged a tie; none judged it worse. This supports modest execution clarity, not demonstrated gains in whole-paper scientific accuracy or reader understanding. Baseline component tests passed; all scripts/components are byte-identical to v2.3. The ZIP and installed files were verified. Complete post-change paper generation, user understanding, and physical touch devices were not tested. Existing dotted version naming is retained despite the generic name validator's restriction.

The v2.3 pre-optimization baseline and older releases remain available.
