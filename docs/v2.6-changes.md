# paper-to-html v2.6 更新报告

发布日期：2026-11-11。上一正式版：v2.5.1。本次发布当前本地 v2.6 的完整 Skill，包含此前暂存包之后已在本地形成的标题与样式调整。未重新生成公开论文案例或批量改写已有阅读网页。

## 读图讲解重组

- 保留并依次区分原文图注与完整翻译、**本图概述**、**作者的结果与判断**。后续带读负责帮助读者找到依据，不重复抄写前面三项。
- 不再让少数图型或每图一个全文模板决定讲法。先拆解对象与测量、数据构造、视觉编码和当前证据任务，再组合必要的讲解动作；复合图、罕见图及新图仍从当前来源重建读法。
- 逐项按当前角色选择解释深度：仅作标识、讲身份或有依据的共性、解释当前作用，或展开必要机制与计算。同一对象可以随任务改变深度；关键分母、对照、反例可能比一批名称更值得展开。
- 优先用作者正文明确讨论且当前图可定位的区域带读，核对位置、参照、读数、统计与支持范围。未展示的正文例子不冒充当前格子，图文不一致时保留归属与待查条件，不能迎合结论改读数。
- 用一个要点一个短块、局部对照和必要小表呈现。新稿不强制固定四区、长段、字数或表格数量；关键解释默认可见，局部小图仍须自足。旧 v1 四区输入继续兼容。

## 从定稿到HTML的内容保真

先按完整单位写作并编辑成简洁定稿，保存独立基线，再装配HTML，不在装配时重新总结。新v2内容的build和publish必须传入`--teaching-baseline`；按单元比较文字、数字、顺序、段落/列表/表格结构、稳定块ID、前置保护标识及显式隐藏状态，包括上层容器。

缺少或重复正文容器时拒绝创建基线；丢单元、删块、改数字、重排或引入显式隐藏时拒绝发布，保留原正式入口。术语链接及无意义空白调整可以通过。正常面板初始隐藏与运行后能否正确显示分别检查。

保真比较证明指定定稿未在装配中发生相应变化；它不证明定稿本身科学正确，也不检测所有全局CSS效果或运行后显示问题。每篇论文仍需来源核查与逐面板实际显示检查，不能从缩水后的输出重建基线掩盖差异。

## 页面标题与样式

概述栏使用正式标题“本图概述”。原文图注、本图概述、作者的结果与判断保留浅色背景及左侧边线；新`data-reader-preserve`标识和旧`original`/`unit-summary`类均有样式支持。知识卡与术语配色按用户范围决定，省略知识卡不自动删除上述内容块底色。
