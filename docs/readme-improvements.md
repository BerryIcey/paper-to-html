# 项目首页整理说明

本次整理调整公开介绍和用词，保持 v2.1 为推荐下载，不更换已归档的版本包或标签。本地 v2.2 仍待新文章测试，未作为公开发行版上传。

| 发现的问题 | 本次处理 |
|---|---|
| 安装说明写的是旧包名，实际附件名称不同 | 统一为 paper-to-html-v2-v2.1.zip，并说明解压目录和调用名仍是 paper-to-html-v2 |
| 部分推荐链接指向不断变化的主分支 | 推荐下载与技能内容链接固定到 v2.1，避免把开发中内容当发行版 |
| 文档缺少 v2.2 的状态，容易把本地版本与 GitHub 混为一谈 | 增加本地测试、尚未公开的说明，明确其改动不在 v2.1 包内 |
| “契约”等内部术语缺少直观含义 | 公开主分支和本机说明改为逐图讲解要求、术语选择与知识卡说明、组件使用说明；技术文件名保留，避免破坏引用 |
| 首页信息重复，功能列表与安装步骤较长 | 调整为效果展示、核心能力、三步开始、版本选择、使用边界；演示服务步骤折叠 |
| 视觉以大段文字和旧横幅为主 | 增加阅读界面示意横幅，统一配色、入口、短表格和段落层次 |
| GitHub HTML 文件页可能被误当可运行演示 | 改为直接原始文件下载，并明确保存后浏览器打开 |

保留：中英文独立截图、静态阅读与项目笔记的区别、公开数据范围、版本包校验、历史版本与用户数据。

仍需后续验证的是新文章中的基础知识筛选、专门术语漏选与不同论证方式的迁移。视觉整理不能证明这些问题已经解决；v2.2 需要实际测试后再决定发布。
