# paper-to-html-v2.5 更新报告

更新日期：2026-11-05。正式版本：v2.5（由此前沿用v2.4名称的更新版升级命名）。本次上传的是可跨设备安装的 Skill，不包含当前论文网页、PDF、截图、笔记或私人数据。

## 本次解决的问题

此前图的简短概括、作者结论及详细带读有相互替代的情况；部分小图只给图注或跳转；英文分类、评分来源、统计参照与星号规则解释不足。本次将这些用户反馈落实为写作、装配和语义验收规则。

## 主要更新

1. 保留三层阅读入口：本图在做什么的自然概括 → 独立醒目的“作者的结果与判断” → 详细带读。续改不得相互覆盖；作者结论从正文核对，区分面板结果、联合证据、作者假说与教学解释。设计图说明安排，不制造发现。
2. 每个可切换小图可独立阅读。整图提供跨面板综合，共享背景不能代替局部教学。多分支流程按箭头讲材料、分支、方法、测量对象和输出；局部缩写不复制整图清单。
3. 陌生英文类别与评分须有翻译、含义、数据来源及图中归属。关键方法讲输入、核心处理、输出及读数含义；复杂图走通一个真实例子，按理解需要决定详略，不硬套等量模板。
4. 统计说明须明确检验对象、参照或零假设、检验方法、实际P或阈值、单双侧与校正（仅来源明确时）。区分颜色、形状、大小、效应与显著性；不以“看星号/括号”结束。缺失定义就地标明，不按惯例或邻图填补；发现同类问题排查全篇。
5. 导航最多两级：章节及“图号＋简短图名”；图间正文与原锚点保留。顶部精简为标题、作者、期刊、日期和PDF/原文链接，宽屏期刊/日期/链接同排。
6. 基础版删除独立读者总结与评议，仍保留作者讨论和局限。固定入口默认覆盖，移除备份数量选择、首次弹窗、版本按钮和配套历史轮转；已有历史资料与用户笔记不自动删除。
7. 图例表格列宽修正，长英文分类不再因表格布局挤成过窄一列；同步项目维护模板。
