# 关键单元的详细讲解要求

先按[讲解单位与详略](reading-units.md)选择详讲、简讲或共享比较。本文四区要求适用于选为详讲的单元，单元可包含多个面板或跨图证据；简单图不必套四区。合讲时共同设计与图例只解释一次，各面板独有的比较、结果与边界在共享区明确对应。原图查阅覆盖与详细注释覆盖分别核对。

适用范围先按 cross-domain-reading.md 判断；下文检测、样本、组学及实验例子仅在当前单元适用时调用，不作为所有论文的必填流程。概念是否需要定义统一按 adaptive-concepts.md。
## 要复现的成果形状
每个详讲单元在相应原文/图注、完整翻译和唯一结论模块之后，保留以下阅读区域。它们承载一段已经写通的自然解释，不是分别填写短答案的表单；共享单元不在每幅图重复一份。

1. **带着当前问题读图**：先定位本面板在论证中的问题/角色；存在前后依赖时说明具体未知，再解释适用的材料/条件、参照、方法选择，以及依据怎样变成图上一个元素。按含义写连贯段落，把样本→区域/基因集合→汇总统计的中间步骤写出来。
2. **本图图例与元素**：局部对应表，列“图中位置/原标签/元素”与“含义、单位、方向和读法”。一个面板含多个色标、统计分母或子区域时，分开对应。显微图和流程图也说明对象、标签、标尺和箭头角色，勿补不存在的坐标。
3. **从实际结果读到判断**：带读当前原图可定位的一个实例，再看整体、差异/阴性结果和反例；写清观察怎样支持当前命题、设计减少了何种解释，以及仍不能推出什么。用展开的自然段完成推理，不在认识尚未建立前只讲限制。
4. **还留下什么问题**：解释下一方法为什么能补缺口，或本面板与并行实验的关系。终点面板可以整合答案和成立边界，无需制造下一问；研究顺序不等于发生时间。

不设最低段落数或图例行数；解释是否充分由语义审查决定，结构检查只确认内容存在。图简单时解释可短，图复杂时中间步骤不能省。保持用户已认可的同等完整旧版布局，给旧版补充可审查语义记录，不为改名重排其内容。

先按[source-and-evidence.md的作者上下文规则](source-and-evidence.md#先找作者明确写出的读图目的与结论)查明当前单元的明确目的、结果与结论及其证据范围。将作者目的接入“带着当前问题读图”，将作者结果／结论放进现有唯一结论模块，并在实际结果带读中解释依据。不要用自己设问代替作者已写出的动机，也不要只写读法与限制而遗漏直接答案；说明图可写作者安排和本图作用，不制造实验证明。

## 从概括类别落回可见证据，再做组合总结

当讲解用“早期、混合、偏某谱系、某通路活跃”等类别概括多个基因、集合、细胞签名或模块时，不能只解释缩写和高低，也不能只复述作者结论。依据当前图的实际标签建立读者能查到的对应关系：**特征类别 → 具体基因／集合／参考细胞 → 图中行、列、条或位置 → 相对谁及什么方向 → 为什么共同支持这项判断**。多类、多行且容易混淆时用简明分类表；少数对象可用自然段，不要求每幅图都套表。

先逐类建立认识，再补一段跨类综合：哪些对象共同构成该特征，哪些与相邻类别不同，哪些不变、反向或例外限制了结论。身份解释、单行读数、跨行综合是三个不同层次；“每个缩写都展开了”和“读者能看出哪组高”不能代替最后一层。例如祖细胞与成熟细胞、T系与NK、集合名Up／Down与当前比较方向，均按本文语境分别说明，不能把相关类别合并成同一个含义。

每个被当作图中实例的名称和方向须在当前原图可定位。正文总结涉及完整分析、补图或未展示集合时，明确它的证据范围，不把正文例子伪装成当前top图里的标签；截断名称无法确认就保留未知，不补造全称。多重参照逐项保留，正负分数和热图颜色只按其实际标准化口径解释，不能拿不同基因／不同行的颜色推绝对丰度。

作者归纳与图上读数分别核查。若明确表述与当前可见方向不一致，原文／翻译保留，讲解就地说明差别及待查材料；不要为了接上作者结论把冷色说成高分、忽略反例或编造预处理原因。先给当前图确实支持的正面总结，再给不一致项。将分类、定位、方向、综合和例外的核查结果保存在既有教学／证据台账，不扩成固定全球基因清单或新的学科分类系统。

## 写作先于装配
先写一份能直接回答“为什么做/谁对谁/数据怎么成为图/看到什么/为何能这样判断/还差什么”的聊天式解释，对原图和正文核实，再映射到四个区域。生成批次以完整主图为单位。新文章先在一个复杂面板校准到下方例子的解释链；内部校准通过后继续全篇，无需用户逐图授权。发现统一压缩后，检查全部受影响面板。

论文数据至少保存下面的教学对象。一个 `explain` 短字符串不能替代这些内容；它也不可以在装配时被省略。每张主图完成后立即保存其教学对象，再继续下一张；教学对象是经过审核的装配输入，组装脚本只读取，不覆盖它。修订后重跑必须读取这些对象，不能重新从旧的压缩字段生成讲解。

```python
teaching = {
    'question': [当前问题和设计的自然段, 输入到图上元素的自然段],
    'legend': [{'visual': 实际轴或标签, 'meaning': 对象和单位}, {'visual': 当前色标或分组, 'meaning': 组别和方向}],
    'reasoning': [从真实例子读到结果的自然段, 从整体结果到认识及边界的自然段],
    'next_question': 尚未回答什么以及下一证据为何合适,
}
```

详细单元使用 `scripts/teaching_contract.py` 的 `render_teaching(teaching, prefix, text_renderer)` 装配。保留固定reader组件，函数只输出教学内容。默认详细面板仍接受完整区域检查；简讲及共享面板使用components.md规定的显式模式及理由，共享目标必须是实际存在的详细单元。不能为了通过旧检查给简单图凑文字，也不能用模式标记掩盖未讲清的关键结果。

## 按讲解单位做语义验收
对最终HTML的详细或合讲单元做遮住原文/译文后的复述，随后重新对照来源；共享区逐一核对纳入证据的独有信息。简讲单元核对图注与必要说明是否足够。记录可审查的答案而非单独勾选passed：

- 当前问题或说明目的；适用的对象/定义、材料、样本及参照。
- 依据如何成为当前元素或关系；定量图解释适用的单位、筛选与汇总，流程/概念图解释节点/箭头。正文或方法未交代的背景/阈值/处理写未知，勿照惯例补。
- 实际可见标签或坐标、它的颜色/数值、比较方向；每个独立色标/分母的角色。作为图上实例的标签/符号必须实际可见，不能拿正文概括或旧论文标签冒充。
- 从该观察到命题的理由；整体、阴性结果、同源汇总与限制。
- 下一证据的缺口及作用。独立验证、并行分支和作者假说分清。

机器检查只报告教学块覆盖；科学核对、独立复述审查、实际浏览器交互、用户理解反馈分别报告。没有可审查复述记录时，不把完整面板计数或可切换称为“带读已验收”。改写期间保留原图/译文/锚点/笔记队列；不覆盖用户认可的另一篇网页。

## 从已认可实例迁移
已认可的聚类面板不是“红高蓝低，说明亚型不同”，而是：不先按突变分组能否看到亚型→每样本从Hi-C取得PC1轨迹→选高变异分箱→计算样本相关并聚类→一个格是两样本相似度→区分左相关色与右A/B色→读取4个HSPC红块及RUNX1/CEBPA群→解释新认识与局限→下一步定位发生转换的分箱。迁移的是这些解释步骤，不能迁移基因、样本数或结论。

GO点图相应要重建：ChIP DNA区域→依论文规则关联候选基因→GO过程注释→与明确或尚未交代的参考背景比较→Count及调整P→一个样本来源/过程的点→真实读数→认识。多块图例必须分别解释。当前图没有的作者正文术语，可以作为正文概括引用，但不能冒充图中标签。

## 回应读者的具体判断
在网页中回应“所以X是否等于Y”一类问题，先准确引述读者相关原话，再逐项回答正确、错误或需限定的部分，接上依据与例子。不用无明确指代的“你的理解方向对”“这里要补充”替代问题对象。已处理记录的完整原话仍留在随手记，正文按需要只引用相关短句；不把个案私有原话打包进通用Skill。
