# 按当前证据组合读图讲解

先按[讲解单位与详略](reading-units.md)选择阅读单位；再判断每项信息需要讲多深。图的外观名称只是线索，不决定整段讲法；不维护封闭图型列表、全球基因深度表或每图一套固定样板。规则同样处理复合、罕见或新图：从当前来源重建读法，不能硬塞到熟悉的几类里。

## 三项前置内容保留

原文图注及完整翻译 → 咱们已有的总结 → 独立醒目的**作者的结果与判断**，依次、分别保留。维护时先核对既有版本，不合并、不缩写、不用新带读覆盖。后三者之外的后续讲解可重组；不为这次升级批量重写旧论文。

新文章的总结让读者认出本图在做什么、展示什么；作者判断从对应Results前后文及必要讨论核对参照、方向、限定和单面板/联合范围。设计图写研究安排，未有独立结论时说明范围，不编造发现。来源规则见source-and-evidence.md；模块存在不证明科学内容正确。

## 先拆关系，再组合动作

制作时判断四个互相独立的维度，记录在既有证据台账即可，不把分析表全部展示给读者：

| 维度 | 需要搞清什么 |
|---|---|
| 对象与测量 | 谁被测，什么材料/尺度，直接观测还是计算推断 |
| 数据构造 | 一个点、格、条、轨道或节点怎样得到；筛选、汇总、归一化、配对和分母是否影响解释 |
| 视觉编码 | 坐标、颜色、形状、大小、箭头、连线及注释各对应什么，哪些层有独立尺度 |
| 证据任务 | 描述、比较、关系、过程、预测、干预、机制或质量检查；本面板在当前论证中做哪一步 |

按理解障碍组合动作：定位对象/参照、解释读数、走通必要构造、作具体比较、归纳共性及例外、连接不同测量、说明判定依据。不要求全部使用、固定顺序或固定标题。复合面板先区分各层及来源，再连接；同一数据的另一种汇总不冒充独立验证。

## 对每一项决定解释深度

| 深度 | 何时够用 |
|---|---|
| 标识 | 编号、位置或已明确名称只用来定位 |
| 身份／类别／共性 | 当前判断只依赖一组对象的共同属性；说明依据、具体对应位置，必要时拆成小组 |
| 当前角色 | 对照、分组依据、测量输出、干预或关键例外影响读图；说明它在这里为何必要 |
| 必要机制／计算 | 不理解独有机制、关系、假设或加工过程，就会把观察解释反或接不上判断 |

这是选择尺度，不是四层都写。同一对象换图、换角色即可改变深度。陌生、高频、名字醒目不等于必须详讲。一个小分母或阴性对照可能比几十个候选更值得讲。删去解释若仍能正确理解当前比较，可压缩；删去会认错测量、比较或证据强度，就补足那个缺口。本文算法本身为贡献时，构造和假设属于核心，不能只解释输出。

批量名称按共性解释须有当前论文或可靠定义支持；“都是基因”通常太宽，名称相似也不足以归入同一通路。共同富集不表示每个成员都同向变化。独有机制、反向项和关键例外另外说。不确定时保留对象与未知范围。知识卡仍按adaptive-concepts.md独立决定，本轮不整体重做卡片系统。

## 先选作者实际讨论且当前可见的例子

先读对应正文前后段、图注与必要方法，找作者明确讨论的观察，再核对是否可在当前图定位。优先级为：作者点名且可定位的关键观察 → 当前图承载主结论的可见区域 → 辅助理解读法的代表区域；必要的阴性对照、例外及矛盾项不因优先级低而省略。数量服从解释需要，不设每图一例上限。

带读自然写成：**先看【行/列、区域、组别或轨道】 → 相对【参照】看到【可见方向/数值】 → 按【当前读数定义】这意味着【该步证据】**。这是核对关系，不是统一栏目或必填话术。后文展示作者判断的依据，避免再抄一遍前面的结论。

每个候选例子核对：名称/位置、比较双方、读数及方向、单位/分母、统计符号、支持范围。作者正文的例子若只在补图、未展示集合或联合分析中出现，就明确指向对应证据，不能伪装成当前一个格子。名称截断、分辨率不足或无精确数时，不补造。没有作者点名区域时可自选，并标为帮助读图的例子，不冒充作者特别强调。

遇到图文不一致先保留原文/译文及作者判断的归属，就地说明当前可见差别和待查条件；不倒转色标、隐藏反例或猜预处理来迎合故事。后续补齐材料再更新。

## 图例、方法与统计必须讲到哪一步

只解释当前图实际存在且影响理解的编码，不逐图复制整图缩写表。陌生评分先交代是什么、来自哪类输入/方法、在本图充当什么读数；算法内部不影响当前解释时无需全部推导，影响成立条件时再展开。标记身份、预后签名、反卷积比例、实测分子量不能混称；预后评分出现在相关图中不等于检验生存。

颜色、点形、面积、误差线、括号、星号可能分别表示不同量。按图注/方法核对检验对象、参照或零假设、独立分析单位、检验方法、实际P/阈值及校正；不把相关检验说成组均值比较，不把富集当单基因表达变化，不以显著性替代效应。未说明、未取得、已核实分别记录；不能按惯例给星号填P<0.05或沿用邻图规则。图只给阈值就不伪造单格P。

热图先判断相关、相对丰度、logFC或标准化量，不能跨行颜色推绝对丰度；富集先判断集合、排序/背景和方向；散点的点可能是细胞、患者、分子或汇总值。没有某种元素就不补不存在的坐标/统计。

## 技术条件按需要补足，例子不封闭分类

| 当前证据组合 | 常见关键条件 |
|---|---|
| 流式门控＋比例 | 各步选中谁，分母如何变化；标记可按身份组合解释，标记本身为干预/结局时另讲 |
| 条带＋定量 | 检测对象、组别、归一化；磷酸化/总量、上样和特异性按当前结论展开 |
| 成像＋空间/邻域统计 | 通道、标尺、分割、采样单位；共定位/邻近/模型推断分清 |
| 单细胞嵌入＋表达＋组成 | 簇是怎样得到，身份依据是什么，细胞内表达和细胞占比是否混淆；细胞数不冒充独立样本数 |
| 轨道＋接触矩阵＋干预 | 参考坐标、分辨率和尺度能否对齐；实测、推断与功能验证分别承担什么证据 |
| 序列/motif/结构模型 | 字母、位置、残基、置信量的含义；预测与直接实验的边界 |
| 筛选＋命中＋验证 | 分数方向、对照、筛选与候选选择；命中不自动证明机制 |
| 生存/预测/模型评估 | 终点、参考组、效应/性能量、训练验证划分和不确定性；模型调整不冒充随机对照 |
| 多分支流程/方法 | 顺箭头说明材料、分装/处理、分支及输出；平行测量不说成依次转化 |

还须主动考虑配对/纵向、谱系追踪、剂量与时间、遗传互作、质量控制、阴性结果、稀少关键异常和多模态不一致。遇到新组合回到四个维度，不再加一整套图型话术。

## 从概括类别落回可见证据，再做组合总结

分类概括须能回到**共性 → 具体标签及图中位置 → 相对谁、什么方向 → 哪项观察共同支持 → 例外**。只需身份时停在共性；承担机制时再展开独有关系。少数对象直接短句，多组易混时用简表；不为每幅图强制加表。作者总体归纳涉及多处证据时保留联合范围，不把单面板说成证明全部。

## 短块呈现与局部自足

最终使用一个要点一个短块、局部对照和必要小表格，可用“先看这一列”“比较这两组”“这里的符号”等短提示。分步呈现复杂推理，不写成长墙，也不压成充满缩写的一句话。读者须能找到看哪里、看到什么、意味着什么；三者可自然连写，不规定三个栏目。简单图可短，复杂图可多块，无字数、段数、表格或固定四区配额。

当前必须理解的条件默认可见；暂不需要的背景可次要呈现，不能靠折叠关键解释制造简洁。可切换小图就地保留对象/读数、必要编码、可见比较及判断理由；合讲共享背景和综合，不能只留图注加“去整图看”。

## 写作、装配与验收

先形成充分分析，再编辑成可直接交付的简洁定稿；每个完整讲解单位保存后继续下一单位。批次不按整篇一次性填满；发现后半部分统一压缩要检查全部受影响单元。新图先用复杂且关键的单元校准深度和短块表现，不以旧例子的基因/数字作为校准词表。

新写采用components.md的v2 blocks接口；旧v1四区继续兼容，但不约束新稿。定稿后按[HTML内容保真](html-teaching-fidelity.md)保存内容及基线，再装配、逐块比对并实际打开检查。装配不重新总结或压缩。结构通过、内容无损、科学正确、实际可读及用户理解分别报告，均不互相替代。

语义检查回到源：对象与层级、具体比较、数据构造/编码、作者例子及范围、共同趋势与反例、证据到判断是否连通。对读者问题先引述相关短句，再说明正确、错误或需限定部分；不把个案私有原话装进通用Skill。
