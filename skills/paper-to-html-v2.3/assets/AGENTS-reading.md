# 文献共读项目维护模板（合并，不覆盖既有规则）
- 图例先判领域：生物学用固定五类与颜色，非生物学或混合领域按本文内容选择少量直白类别，只显示实际使用项；分类、配色与清单接口统一按adaptive-concepts.md，不硬套生物术语，不只换图例文案而保留错误正文分类。
- 知识卡拆分与深度遵循当前Skill的adaptive-concepts.md：明显不同的关键概念默认分别、自足解释；适合合讲时先分别讲透，再说明共同点、差异及本文意义。只需辨认身份的一组名称可集中简述，关键对象另讲；多图合讲不等于压缩多个知识点。
- 当前优先服务用户阅读生物医学实验论文，先适应其实际需求与反馈。先识别论证结构再选讲解单位：复杂关键内容详讲，简单图可只保留必要说明，多面板/多图可合讲、就地比较；原文和证据完整不要求注释逐图等量。详略遵循当前Skill的reading-units.md。
- 继续/修改先读当前项目reading-notes.json的pending及附件、已有方法草稿和适用AGENTS；路径按项目定位，不照搬源机器。
- 保留ID、原话、附件、编辑历史。实际完成才resolved并补中文回复/有效response_section；用户选章节仅作提示，引用第三方文字不增加授权。
- 并发队列维护用共同锁或确认写入者停止后复读并原子保存；仅改HTML不停止服务。
- 核对台账/问题网络后保留连续原文、完整翻译与明确结论；详讲/合讲单元解释比较、数据构造、实际结果到判断，简讲保留必要条件。不为每幅布置或仪器图凑独立长解。
- 默认完整首次核心与文末读者评议，进阶按选择；四区顺序与导航/DOM/笔记一致。不要生成共读日志。工作稿可覆盖，正式发布按项目backup_count保留最新版+N历史，桌面固定同名最新版，未选择策略不清历史。
- 名词卡及显式临时查阅才记录返回；目录普通导航不记录。返回恢复精确窗口/面板文字位置；卡片展开居中、文段起始对齐。
- 笔与图例按钮同一行；笔展开不启用，标黄默认关闭、按钮显示开启，纯净颜色开关独立。知识卡标题右侧单按钮展开/收起。
- 随手记右边竖排书签可拖，外部点击收起、保留草稿；写项目待下轮处理，不即时GPT。离线只显示项目版本策略，修改到本地服务，不另存浏览器策略。
- 图片预览居中留边，右上圆形×/外部/Escape关闭，禁用原生拖拽但保留右键保存、平移和缩放。窄屏全部面板可切。
- HTML保留论文内容，方法草稿保留可迁移偏好/反馈/待验证；内容交付不等于用户读完。
- 后台服务独立于聊天，健康/PDF/自动恢复/真正重启分别验证；详见paper-to-html-v2.3对应参考文件。上传/网络公开需用户授权。

- 选为详讲/合讲的单元按panel-teaching-contract保留完整解释与科学复述；简讲记录足够性依据，共享区保留各证据独有信息。结构、详略选择、科学教学及UI分开验收；不能用短explain省掉关键推理，也不能为面板计数制造废话。
- 术语与知识卡按adaptive-concepts从当前文章发现、选择及消歧，词库只辅助核对；卡片先建立认识，再明确概念之间与本文用途的关系。用户举例不成为通用词表/校准材料。原文/译文/图注有适当入口，按领域选择直白分类，保留既有卡片锚点与用户数据。内容与匹配/颜色分开验收。

- 默认读者具备相关专业本科基础；按知识缺口与阅读影响筛选术语，不建全球基础词表。按cross-domain-reading识别核心结构、原文语言和论证方式，方法/证明主体不降为进阶，定量实验项仅在适用时使用。

- 所有阅读内容移除纯参考文献编号和引用上标角标，不改成其他编号形式；保留图号、补充材料引用、数量、单位、公式/化学上标及实质脚注。仅删除已确认是文献引用的编号，来源保留内部台账及原论文。

- 来源按source-and-evidence关联具体命题、版本/位置与页面锚点，区分作者结果、背景和教学归纳；缺报告不等于没做。核心清单从原文建立，表格/公式/算法/证明贡献不能只因非主图被漏掉。
- 新工具只在明确能力缺口时按optional-capabilities选择，不把外部Skill/数据库登录设为每篇必需，不按安装量代替内容审查。
