# 来源与证据核对

用于读入论文、补术语定义、评议作者主张及最终核对。本文提供查询与判断步骤；不是内置百科，也不要求每篇联网查遍所有数据库。

## 确认正在读哪一份
先核对用户文件的题目、作者、年份、DOI或其他稳定标识、版本和补充材料。用户提供的版本是当前阅读对象；发现正式版、更正、撤稿或更新时记录差异及其影响，不能悄悄换文后混用面板/页码。没有DOI的论文照常处理。

联网可用时，在作者/出版社记录核对身份和重要更新；按需要用下列服务定位。网络不可用、未收录或接口失败时记录本次核查边界，继续处理现有资料；未查到更新不等于已证明没有更新。

| 要解决的问题 | 优先入口与适用边界 |
|---|---|
| DOI身份、出版元数据、关联更正/撤稿 | [Crossref](https://www.crossref.org/documentation/retrieve-metadata/rest-api/)与[Crossmark](https://www.crossref.org/services/crossmark/)；未覆盖的记录再查出版社，不把API缺字段当否定证据 |
| 跨领域查找论文和可获取版本 | [OpenAlex](https://help.openalex.org/data/works/open-access/)；核对标识、作者、年份和版本，标题相似或推荐排名不足以确认同一篇 |
| 寻找合法可读副本 | [Unpaywall](https://unpaywall.org/data-format)或官方仓储；区分published/accepted/submitted版本，重新核对图号、图注与正文；免费可读不自动等于可公开再分发 |
| 核对数据、代码或领域对象 | 从本文Data/Code Availability、稳定标识、官方数据库和作者指定版本进入；领域资源按本篇对象选择，不固定为生物医学数据库 |
| 补定义、假设或方法机制 | 本文定义/方法优先；需要一般解释时再查标准、原始方法论文、维护方官方文档或学术教材，并回到本文核对该含义是否适用 |

数据库元数据用于定位；搜索摘要、引用次数、生成式摘要、词库命中都不能代替读到支持该句主张的正文。标识或版本冲突未解决前不合并来源。API配额、认证、端点可能改变，真正调用前查当前官方说明；不内置用户邮箱/密钥，不为读一篇论文下载全库。

## 把解释连回具体来源
复用文章已有证据台账，不另造重复记录体系。对影响结论的主张/概念保留：

- `claim_id`及它要表达的命题；`kind`区分作者原述、图中观察、外部背景、教学归纳或未核实项。
- `source_id`：文件/URL、版本或日期；PDF保留页码/图号/裁区，HTML保留小节和足以辨识的原文短引。文件易混淆时记录哈希。
- `locator`及必要的原文短引；`target_id`指向实际网页讲解/卡片锚点。引文定位不凭页码单独推断语义。
- `status`、缺失/冲突及其对当前判断的影响。缺补图只限制依赖该补图的结论；不要把其他已核对内容一并说成未知。

借鉴[W3C Web Annotation](https://www.w3.org/TR/annotation-model/#text-quote-selector)把内容关联到资源片段的做法；这里只是轻量制作台账，不宣称实现JSON-LD或整套W3C协议。台账是内部制作依据，不增加网页阅读日志。阅读区仍按原规则隐藏纯文献编号；必要外部来源使用可理解的命名链接，保留原论文入口。

## 先找作者明确写出的读图目的与结论

写“为什么做这张图”与“这张图说明了什么”前，先查找作者的明确表述，不能只凭图像、图注或自己重建的故事写作。按需要查对应Results前后段、引言中的研究问题、图注、该小节总结和相关Discussion；图号是检索线索，作者的目的或总结可能没有重复图号。核实句子对应当前面板、整张主图还是多图联合证据。

- **目的先接作者的话**：找到明确目的，就把它忠实转述到图旁，交代对象、比较及想理解的问题。作者只给了整段实验的共同目的时，说明这是本图所属实验的目的，再解释本面板承担哪一步；不要编造更具体的作者动机。
- **结论先说直接答案**：找到当前图对应的结果或结论，就明确写“作者在正文中指出／作者据此认为”，保留参照、方向和“提示、可能”等限定语。随后从实际图中元素说明依据。限制放在读者已知道结果之后，不能用一串边界代替作者已讲清的发现。
- **按证据范围归属**：研究设计、概念或数据层次图说明作者安排了什么，研究目的不是已经得到的结果；需要多面板／多图支持的总结写“合看这些证据，作者概括为……”，不让某个小图独自承担全部结论。Discussion中的机制假说仍标为作者解释或假说。
- **缺少明确句时再归纳**：记录已查范围；若作者只给出目的而未单独给面板结论，说明本面板展示什么。补充推理写“据图可归纳／带读理解”，不要伪装为作者原话，也不为每幅简单图硬凑结论。作者表述与图／图注冲突时忠实保留并就地说明差异，不暗改或照抄成已证实事实。

在已有证据台账为相应讲解单元记录 `author_purpose`、`author_conclusion`、`source_locator`、能精确回查的 `source_excerpt`、`scope`（面板／主图／联合证据／讨论解释）和是否含 `teaching_inference`。只有意译时不使用原话引号。台账用于核对；页面自然呈现作者目的、答案及依据，不堆制作字段或重复来源定位提示。

例如作者在某说明图附近写“为理解这一表型的调控基础，我们比较数类样本的表观遗传和转录图谱”，就把这项明确研究目的接到说明图中；该图的直接作用是交代比较对象与测量层次，具体调控发现仍要接到真正报告结果的面板。例子只说明归属判断，不作为固定论文事实或模板必填句。

## 先读出证据，再评价主张
先向读者建立本文的正面认识，再在该判断处给相关边界。每条重要评议采用“源位置→可核对观察→影响哪项主张/为何→还需什么信息才能判断”的顺序，避免只有泛泛注意事项。

- 实证/统计：区分描述、预测、因果；核对独立分析单位、参照、效应大小、区间/不确定性、假设和选择过程。未显著不自动等于无效或等效；不同人群的两项估计不能只凭数值高低宣布优劣。同一数据的重新汇总不算独立复现。
- 推导/证明：核对定义域、量词、假设、关键推导和结论适用范围；数值例子不代替证明，缺失推导明确定位。
- 算法/系统：区分方法描述、理论保证和测试结果；核对任务、基线、公平比较、数据划分/泄漏及适用分布，按文章有无相关评估决定检查项。
- 概念/文本论证：核对材料出处、语境、概念使用和推理桥梁，说明竞争解释如何被处理；不强塞实验统计。

“没有报告”“未取得资料”“明确没有实施”“有反对证据”分别记录；不从缺少叙述推断作者没做。报告完整、偏倚风险和某项结论的证据把握是不同问题，不按清单勾选数给整篇质量分。正式GRADE/RoB等工具只有当研究类型、评价单元及用户任务适合时才采用，并查其当前原始指南，不作为通用论文带读默认流程。

以上审查方式参考 scientific-critical-thinking 与 citation-management，并按单篇共读缩减；版本、来源和取舍见[外部能力选用](optional-capabilities.md)。
