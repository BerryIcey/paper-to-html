# 范围边界与必要适配

当前主范围是为用户阅读生物医学实验论文提供中文共读。先按reading-units.md决定讲解单位与详略，优先用用户实际论文及反馈验证。以下是遇到其他论证类型时的备用判断，不要求每次同时适配、检验所有领域，也不宣称全领域能力已经成熟。

复用判断过程与阅读组件，不复用领域知识目录。先核对本文实际语言、章节、主贡献、证据或推导方式；混合文章按单元适配，不要求整篇只能归一类。下列方式是帮助判断的例子，不是封闭领域清单。

| 当前论证方式 | 解释重点 |
|---|---|
| 实证观察、实验或模拟 | 对象和条件、测量/模型、比较、数据处理、实际结果、推断及限制 |
| 形式推导、定理或证明 | 命题、定义和符号、假设、关键推导、结论成立条件与反例；不编造对照组或观测数值 |
| 算法、方法或系统设计 | 问题、输入输出、关键步骤及为何成立、适用条件；有评估时解释评估，无评估时不补造实验 |
| 概念、材料解释或文本论证 | 主张、材料或概念依据、解释步骤、竞争论证、适用范围；不强塞统计显著性或生物机制 |

共同要求是问题、依据如何形成、推理如何支持判断以及边界。主线可以是并行、递进、反证或定义依赖，不能把所有链路改成“上一实验不足所以做下一实验”。末尾可以整合答案，无需制造下一问。

保留实际章节身份与连续论证。原文不是英语时使用真实原文；中文共读是默认语言偏好，不是来源限制。独立 Methods 若是贡献主体就属于核心；按需省略的是复现级细节，而不是整章。公式、表格、算法框和证明可能承载关键贡献，不能只以主图覆盖衡量完整性。

图按当前视觉元素重建读法：元素、编码关系、依据、实际含义和可支持判断。定量图解释单位与统计，流程/结构图解释节点与箭头，示意图区分说明与观测。不存在的轴、图例、数值或下一实验不补造；适用项简单时不凑段数和行数。必要信息不能为了紧凑被省略。

已有组学与医学校准案例是可选领域参考，不是通用实验顺序。源核对、诚实表达未知、逻辑连贯和用户数据保留等通用要求仍适用。保留已认可布局和控件；本轮适配不要求重做界面。语言变更请求只调整相应显示文案与内容，结构检查优先使用 data 属性；旧中文标题仅用于历史格式兼容。

验收须同时检查遗漏与强套：关键方法/证明/材料是否完整、专门概念是否漏选、基础知识是否过选、有无把非实验论证改写成实验故事。迁移结论只能覆盖实际审查过的文章和单元，不能因术语链接测试通过宣称所有领域已验证。

## 核心不只在图里
从原文独立列核心对象并保留标识与页面锚点，逐项说明“当前问题→表示/构造→实际内容→推理及边界”。已有图文原文/译文/结论/解释结构继续复用，不为凑面板把这些对象伪装成图片或新造下一实验。

- 表格：先交代行/列/单元格和参照，再读一条真实记录、单位、分母与不确定性；解释脚注/缺值及能否横向比较。表格说明中的实质脚注保留。
- 公式：定义符号、索引、定义域、单位及假设，说明关键变形为何成立、公式解决什么；教学代入明确标示，不能当作者测得的数据。
- 算法/伪代码：交代输入输出、状态/步骤及关键机制，解释作者给出的复杂度或保证及条件；没有证明/评估则不补造。代码和公式内部不自动插入术语链接。
- 命题/证明/文本材料：先建立命题或材料语境，再解释关键依赖、推理桥梁与结论范围；区分作者证明、直观帮助及尚未成立的猜想。

验收将原文核心清单对照最终HTML锚点，分别记录已讲解、缺资料或未完成；清单本身和结构字段不能证明内容正确。没有图的文章不因面板数为零被判成无贡献；有全部主图的文章也可能缺关键表格或推导。
